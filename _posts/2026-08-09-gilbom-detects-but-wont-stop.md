## 증상

실외에서 점자블록을 분명히 감지한다. 로그에도 찍힌다. 그런데 로봇이 **그냥 지나간다.** 정차하지 않으니 파손 판정도, 사진 촬영도, 보고도 없다. 미션의 핵심 흐름 — 발견 → 정차 → 판정 → 보고 — 이 통째로 끊긴 것이다.

## 원인 — 값이 아니라 값 사이의 관계

관련된 타이머는 둘이었다.

- **정지 진입 2.0초** — 블록을 발견하면 TRACE 상태로 들어가며 2초 동안 멈춘다 (오탐 방어 + 탐지 카메라 안정)
- **소실 확정 1.5초** — 블록이 1.5초 동안 안 보이면 "잃어버렸다"고 확정하고 순찰(CRUISE)로 돌아간다

둘 다 따로 보면 타당하다. 문제는 **정지 진입이 코스팅(관성 주행)이었고, 소실 확정이 그 정지를 도중에 끊을 수 있었다**는 것이다.

```
감지 후 경과 시간 ──────────────────────────▶
0s        1.5s 소실 확정 ✕      2.0s 정지 진입 완료
│           │                     │
│  감속 중  │ "블록이 안 보인다"  │
│           │ → CRUISE 복귀       │  ← 여기 도달하기 전에 이미 끝났다
```

블록에 붙을수록 **주행 카메라 화각에서 블록이 최하단으로 빠져나간다.** 세그 목표가 흔들리고, 1.5초 뒤 소실 확정이 나고, 정지하던 로봇은 CRUISE로 복귀해 다시 달린다. 한 프레임 발견 → 정지 도중 소실 확정 → 복귀. 정지·감속·추종이 전부 무효였다.

<div class="warn">정지보다 소실 판정이 먼저 끝났다. 각각은 멀쩡한 값들이 만나 시스템을 죽였다. 그리고 그 구간의 진짜 관측 — 하향 탐지 카메라에는 블록이 아주 잘 보인다 — 은 버려지고 있었다.</div>

## 해결

### 1. 정지 창을 소실 판정에서 분리

TRACE 진입 정지를 **2초 브레이크, 소실과 무관하게 끝까지 지킨다**로 바꿨다(`trace.entry_stop_sec`). 정지 중에 블록이 안 보이는 것은 정상이다 — 가까워서 화각 밖으로 나간 것이니까.

정지가 끝난 뒤에도 블록이 안 보이면 바로 포기하지 않고 **탐색 주행**(`trace.search_sec` 4초)을 한다. 마지막 관측 방향으로 60% 속도로 전진하며 재획득을 시도한다. "멈추고 → 알리고 → 블록을 찾아서 이동." 창이 끝나도 없으면 그때 순찰로 복귀한다.

### 2. 세그 + HSV 이중 관측

세그멘테이션이 놓치는 그 구간을 **하향 탐지 카메라의 노란색 관측**으로 메웠다. 점자블록은 노랗다. HSV 색공간에서 노란색 픽셀 비율이 임계(4%) 이상이면 발견 히트로 센다(`perception/yellow.py`).

- YOLO 추론은 수백 ms, HSV 마스크는 **수 ms**다. 매 프레임 돌려도 부담이 없다
- 노란색이 잡히는 동안은 **노란색 무게중심을 따라 40% 저속**으로 천천히 탐지하며 간다(`trace.detect_follow`)
- 세그가 놓쳐도 하향캠이 노란색을 보는 동안 추종이 안 끊긴다

```python
# perception/yellow.py 의 아이디어 — HSV 노란색 비율과 무게중심 (수 ms)
hsv = cv2.cvtColor(frame, cv2.COLOR_BGR2HSV)
mask = cv2.inRange(hsv, lower_yellow, upper_yellow)
ratio = mask.mean() / 255.0            # 임계 4% 이상이면 "블록이 보인다"
m = cv2.moments(mask)
cx = m["m10"] / m["m00"] if m["m00"] else None   # 추종 목표
```

### 3. 관제에 한 번만 알리기

첫 감지 1회만 웹 관제 대시보드에 "점자블럭 감지, 탐지 모드 진입하겠습니다" 토스트를 띄운다. 확인 버튼 없이 2.5초씩 두 번. IDLE로 돌아가면 리셋돼 다음 미션의 첫 감지는 다시 알린다. 시연에서 "지금 뭘 하는 중인지"가 보이는 것이 중요했다.

## 결과

미션 핵심 흐름이 복구됐다. 발견 → 2초 정지 → 탐지 카메라로 판정 → 정상이면 즉시 재개 / 파손이면 1초 추가 정지 후 보고 → 재개.

<div class="tip">단일 값이 아니라 값 사이의 관계를 본다. 2.0초도 1.5초도 각각 옳았다. 둘의 순서가 틀렸다. 타이머가 둘 이상이면 "누가 먼저 끝나는가"를 그림으로 그려 보는 습관이 생겼다.</div>
